# SeatFlow (실시간 스터디룸/좌석 예약 시스템)

바닐라 PHP와 MySQL(PDO)로 구현하는 실시간 스터디룸 및 좌석 예약 웹 애플리케이션입니다.

## 주요 기능 (예정 및 진행)

- **룸 및 좌석 현황 조회**: 스터디룸/열람실(`rooms`)과 좌석(`seats`) 상태(`active`, `maintenance` 등) 확인
- **회원가입 및 로그인**: 세션 기반 인증 및 비밀번호 해싱(`password_hash` / `password_verify`)
- **실시간 좌석 예약 및 중복 방지**: 시간대 겹침 검증 및 트랜잭션 처리(`reservations`)

## 기술 스택

- **Backend**: Vanilla PHP (PHP 8.5), PDO (`pdo_mysql`)
- **Database**: MySQL (`seat_flow`)
- **Frontend**: HTML, CSS, JavaScript
- **Local Server**: PHP Built-in Server (`php -S localhost:8000 -t public`)

## 로컬 실행 방법

1. MySQL에서 `seat_flow` 데이터베이스 생성 및 테이블(`users`, `rooms`, `seats`, `reservations`) 구성
2. 루트 경로의 `.env` 파일에 DB 접속 정보 설정
3. 프로젝트 루트에서 PHP 내장 서버 실행
   ```bash
   php -S localhost:8000 -t public
   ```

## 핵심 구현 포인트

### 1. 홈 화면 통합 예약 및 사용자 피드백 흐름

- **방식 A(단일 화면 통합) 채택**: 홈 화면(`Views/home/index.php`)에서 룸·좌석 실시간 현황 조회와 즉시 예약 폼을 함께 제공해 탐색부터 예약 신청까지 페이지 이동 없이 처리할 수 있도록 구성했습니다.
- **PRG(Post-Redirect-Get) 및 플래시 상태 유지**: 예약 요청(`POST /?action=reservation_create`) 처리 후 리다이렉트 시 세션 플래시 메시지(`$successMessage`, `$errorMessage`)와 이전 입력값(`old_reservation`)을 전달해 검증 실패 시에도 사용자가 선택한 좌석·날짜·시간을 유지한 채 원인을 확인할 수 있습니다.

---

### 2. 트랜잭션 잠금 기반 중복 예약 방지 및 시간 경계 처리

동일 좌석·시간대에 여러 요청이 동시에 들어오는 상황에서도 데이터 정합성을 지키기 위해 `ReservationRepository::createReservation()` 내부에서 트랜잭션과 행 잠금(`FOR UPDATE`)을 적용했습니다.

1. **좌석 상태 선잠금 및 검증**: 대상 좌석(`seats`) 행을 먼저 잠근 뒤 존재 여부와 이용 가능 상태(`active`)를 확인합니다.
2. **시간 겹침 조건 검사**: 동일 좌석·날짜의 확정(`CONFIRMED`) 예약 중 기존 시작 시각이 새 종료 시각보다 이르고, 기존 종료 시각이 새 시작 시각보다 늦은 건(`start_time < :end_time AND end_time > :start_time`)을 겹치는 예약으로 판별해 차단합니다.
   - 겹치는 시간대(예: `10:00~12:00` 예약 존재 시 `11:00~13:00` 요청)는 차단합니다.
   - 종료 시각과 시작 시각이 맞닿는 인접 시간대(예: `10:00~12:00` 이후 `12:00~14:00` 요청)는 정상 허용합니다.
3. **원자적 등록 및 예외 롤백**: 검증을 통과한 경우에만 예약을 등록하고 커밋하며, 검증 실패 또는 예외 발생 시 `rollBack()`으로 상태를 복구합니다.

---

### 3. 실시간 좌석 상태 및 점유 배지 판별

좌석의 물리적 운영 상태와 현재 시각 기준 예약 점유 상태를 분리해 화면에 직관적으로 표시합니다.

| 구분             | 판별 기준                                                                   | 화면 표시           | 예약 가능 여부               |
| :--------------- | :-------------------------------------------------------------------------- | :------------------ | :--------------------------- |
| **점검 중**      | `seats.status !== 'active'` (`maintenance` 등)                              | `점검 중` 배지      | 선택 비활성화 및 서버 차단   |
| **현재 이용 중** | `active` 좌석 + 현재 시각에 걸린 `CONFIRMED` 예약 존재(`is_in_use_now = 1`) | `현재 이용 중` 배지 | 다른 비겹침 시간대 예약 가능 |
| **이용 가능**    | `active` 좌석 + 현재 시각 기준 확정 예약 없음(`is_in_use_now = 0`)          | `이용 가능` 배지    | 예약 가능                    |
